        Help & setup

        1 · Sheet layout

        One tab per topic. First row = headers (optional). VocabLab auto-detects these columns (English or Vietnamese names):

        ColumnPurpose
        Vocab / Từ vựng / Wordword or phrase you are learning (required)
        Vietnamese / Nghĩa / MeaningVietnamese meaning (required)
        Pronunciation / Phát âm / Pinyinspoken hint, shown on the word card
        Example / Ví dụexample sentence (also used for fill-in-the-blank)

        2 · How VocabLab reads your sheet

        Option A — Sheets API key (automatic, needs a key): share sheet as “Anyone with the link”, create a free API key with the Sheets API enabled, paste both in Settings → Google Sheet. Every tab loads automatically.

        Option B — Apps Script (no Google Cloud): in your sheet open Extensions → Apps Script, paste this, then Deploy → New deployment → Web app (Execute as Me, access Anyone) and paste the /exec URL in Settings:

        function doGet() {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var out = ss.getSheets().map(function (sh) {
    return {
      title: sh.getName(),
      values: sh.getDataRange().getDisplayValues()
    };
  });
  return ContentService
    .createTextOutput(JSON.stringify(out))
    .setMimeType(ContentService.MimeType.JSON);
}

        Option C — Sheet link (easiest, no key): share the sheet as “Anyone with the link → Viewer”, then in Settings → Google Sheet → Sheet link paste just the sheet link. VocabLab downloads the sheet's own preview to detect every tab (topic) — new tabs appear automatically after ↻ Reload. On a double-clicked file:// page, where that download is blocked, it asks the public r.jina.ai reader for the same tab list instead (still no key, nothing to type), and otherwise reuses the tab list remembered from the last load. To load only some topics, put tab names on separate lines under the link; Topic name | URL lines (published CSV or #gid=…) also work.

        3 · AI questions

        Pick a provider in Settings → AI — every one of them works; the menu is the whole list, not a choice between “Gemini” and “other”. Google Gemini is the default (paste a free Gemini API key), and all the rest are OpenAI-compatible services with their own key: Groq (free, very fast), Cerebras (free trial credit), OpenRouter (free models), Mistral, DeepSeek (paid, very cheap), Cloudflare Workers AI, or a local Ollama (no key; run it with OLLAMA_ORIGINS=*). Pick one, paste its key, press “Test & load models”. Each provider keeps its own key, so you can switch back and forth without retyping. Questions are generated in small batches and cached, so replays barely use quota. If the key is missing or quota runs out, the built-in generator takes over automatically — the app never gets stuck.

        3b · Paragraph translation

        Tick Paragraph translation in the setup, choose the direction (French ➜ Vietnamese, Vietnamese ➜ French, or both) and how many paragraphs. The AI writes a short text from your own sheet words and lists the 5–6 words you must use next to it; write your translation in the box and press Check with AI. The correction keeps your wording wherever it is acceptable and only fixes real errors (spelling, accents, agreement with your subject, prepositions, a word that changes the meaning). Your own pronoun, tense and synonyms are fine — the reference translation is only a guide to the meaning, never the answer you had to produce. The feedback shows your text, the fixed version, one short note per actual change, and which sheet words you used. This exercise is AI-only: with no key (or Generator set to Built-in) the option is disabled and says why, and a failed generation is reported in Settings → AI rather than replaced by another question type.

        Troubleshooting

        • 403 from Sheets — the sheet isn't shared as “Anyone with the link”, or the API key has restrictions that block the Sheets API.
        • “API has not been used / disabled” — enable the Google Sheets API for your key's project.
        • AI errors — check the key in Settings → AI (“Test & load models”), or switch Generator to Built-in. The app keeps the whole explanation in Settings → AI.
        • Ollama / local server — Ollama is a program on your computer, not a web service: install it (ollama.com/download), run ollama serve, then ollama pull llama3.2. “nothing is running there” means VocabLab couldn't find it on that port; “a server answered, but it blocked this page” means CORS (OLLAMA_ORIGINS=*, and serve this page over http(s)://).
        • 429 quota — free-tier limit hit (Gemini's daily free quota is per project). Wait a minute, or pick another provider in Settings → AI: Groq, Cerebras and OpenRouter have free tiers of their own. Built-in questions cover the rest meanwhile.
        • Network errors — if you opened the file directly (file://), try serving the folder (python3 -m http.server) or hosting it. Some browsers restrict cross-site requests from local files.
