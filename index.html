            Help & setup

            Account & daily quests

            VocabLab opens on a sign-in screen. Create an account with a name, email and a password of at least 8 characters. Your name, daily quests and streak sync to the MongoDB Atlas database configured for this deployment; the deck, word progress, grammar progress, settings and recordings stay in this browser. You can still use the app offline after signing in: quest progress is cached and sent when the connection returns.

            Recovery code: at signup you get a one-time code. It is shown once, so save it. To reset a forgotten password, choose Forgot password? and enter your email, that code and a new password. The code is rotated after a successful reset. There is no email reset link and no other recovery path.

            Three quests a day — one quiz (multiple choice or mixed), one production (paragraph or shadowing) and one review (flashcards or grammar). The set is picked deterministically for your account and today's local date, so a reload never rerolls it, and it refreshes at your local midnight (or when you return to the tab). Start opens that exact practice. Bars fill as you answer, record or finish a lesson, and progress accumulates across sessions.

            Streak: finish all three quests to add a day. Missing one day keeps the streak with a ! warning; finish today and it continues. Missing a second day resets it to 0 (your best streak is kept).

            1 · Sheet layout

            One tab per topic. First row = headers (optional). VocabLab auto-detects these columns (English or Vietnamese names):

            ColumnPurpose
            Vocab / Từ vựng / Wordword or phrase you are learning (required)
            Vietnamese / Nghĩa / MeaningVietnamese meaning (required)
            Pronunciation / Phát âm / Pinyinspoken hint, shown on the word card
            Example / Ví dụexample sentence (also used for fill-in-the-blank)

            Rule-based, not AI-guessed: headers are matched by name (accent/case-insensitive); with no header row, column 1 = word and column 2 = meaning. Empty rows, duplicates, repeated headers and emoji section rows are skipped, and so are hidden tabs. The AI only writes questions from these words — it never decides which column is which.

            2 · How VocabLab reads your sheet

            Option A — Sheets API key (automatic, needs a key): share sheet as “Anyone with the link”, create a free API key with the Sheets API enabled, paste both in Settings → Google Sheet. Every tab loads automatically.

            Option B — Apps Script (no Google Cloud): in your sheet open Extensions → Apps Script, paste this, then Deploy → New deployment → Web app (Execute as Me, access Anyone) and paste the /exec URL in Settings:

            function doGet() {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var out = ss.getSheets().map(function (sh) {
    return {
      title: sh.getName(),
      values: sh.getDataRange().getDisplayValues()
    };
  });
  return ContentService
    .createTextOutput(JSON.stringify(out))
    .setMimeType(ContentService.MimeType.JSON);
}

            Option C — Sheet link (easiest, no key): share the sheet as “Anyone with the link → Viewer”, then in Settings → Google Sheet → Sheet link paste just the sheet link. VocabLab downloads the sheet's own preview to detect every tab (topic) — new tabs appear automatically after ↻ Reload. On a double-clicked file:// page, where that download is blocked, it asks the public r.jina.ai reader for the same tab list instead (still no key, nothing to type), and otherwise reuses the tab list remembered from the last load. To load only some topics, put tab names on separate lines under the link; Topic name | URL lines (published CSV or #gid=…) also work.

            3 · AI questions

            Settings → AI has two modes. Simple (the default) uses a free model that needs no account and no key: pick a model and start a quiz. It is a shared public service limited to one request every 30 seconds, so VocabLab batches up to 20 words per request and waits for the next free slot when it has to (a paragraph costs one request to write and one per correction check, up to the retry limit). For heavy use, Advanced with your own key has no such queue. Advanced is for your own provider and key — the menu is the whole list, not a choice between “Gemini” and “other”. Google Gemini is the first one (paste a free Gemini API key), and all the rest are OpenAI-compatible services with their own key: Groq (free, very fast), Cerebras (free trial credit), OpenRouter (free models), Mistral, DeepSeek (paid, very cheap), Cloudflare Workers AI, or a local Ollama (no key; run it with OLLAMA_ORIGINS=*). Pick one, paste its key, press “Test & load models”. Each provider keeps its own key, so you can switch back and forth without retyping. Questions are generated in small batches and cached, so replays barely use quota. If AI is unavailable or quota runs out, the built-in generator takes over automatically — the app never gets stuck.

            Difficulty (Easy / Standard / Hard) sets the sentence length and CEFR level of AI questions and paragraphs. The optional Topic or focus box takes a short instruction, e.g. “short sentences about city life; focus on the passé composé”, and the suggestion chips add common themes. Both settings steer AI questions and the paragraph exercise; the built-in generator ignores them. Question count, direction and the generator are under More options in the Quiz tab.

            3b · Paragraph translation

            Paragraph translation is its own practice mode, not a quiz type: open the Paragraph tab, choose its direction (French ➜ Vietnamese, Vietnamese ➜ French, or both) and how many paragraphs, then press Start paragraph. The AI writes a short text from your own sheet words and lists the required words next to it (4–5 on Easy, 5–6 on Standard and Hard); write your translation in the box and press Check with AI. The shared Difficulty also controls the text length — Easy 3–4 sentences, Standard 4–6, Hard 6–8 — and Topic or focus guides its subject and style. The correction keeps your wording wherever it is acceptable and only fixes real errors (spelling, accents, agreement with your subject, prepositions, a word that changes the meaning). Your own pronoun, tense and synonyms are fine — the reference translation is only a guide to the meaning, never the answer you had to produce. The score still reflects the source's ideas and the required words: leaving out an idea or a required word costs points even when the grammar is fine. The feedback shows your text, the fixed version, one short note per actual change, and which sheet words you used. When the AI finds something, the paragraph stays editable: press Apply fixes and edit, change anything you like, then Check again. Each paragraph gets at most three AI checks. The attempt is only scored when the AI says it is all good; after the third check, Finish anyway is offered (using the last score), and the feedback shows each attempt's score. This exercise is AI-only: if AI is not set up, Start paragraph is disabled and says why, and a failed generation is reported in Settings → AI rather than replaced by another question type. The quiz Generator setting does not affect paragraph practice — it always uses AI.

            3c · Shadowing with pronunciation feedback

            Shadowing is its own practice mode. Open Shadowing, press Start shadowing, and the AI writes a short French paragraph from your sheet words. Listen to one sentence, then press Record and say it yourself. Replay it as often as you like; the translation stays hidden until you press Show translation. Press Check pronunciation and the scoring engine you chose in Settings → Speech listens to that one recording. You get an overall score plus accuracy, fluency and completeness, word-level highlights, and two short practice tips. Record again after listening, then move to the next sentence. The summary shows your average and each sentence's score.

            Gemini scoring (the default when a Gemini key exists) sends a short WAV clip to Google's free tier and asks the model to transcribe and judge it. It is an AI estimate, not a certified test, and it uses no Azure speech hours. Azure scoring returns real word-level pronunciation assessment but consumes your 5 free speech-to-text hours. Switch engines with Settings → Speech → Pronunciation scoring.

            Recording works in every current browser without a key. Azure Speech adds the natural cloud voice: create a free Speech resource in Azure, then paste its key and region in Settings → Speech (free F0 includes 5 audio hours and 500K characters a month; a card may be required by Azure). The key stays in this browser. A recording is kept in memory only until you press Save; saved recordings go to this browser's IndexedDB and are never uploaded to this app's server or database. Leaving shadowing, moving to the next sentence, finishing, starting another recording, or closing the tab deletes anything unsaved. Gemini or Azure receives the audio only when you press Check pronunciation (Azure also receives text for the cloud voice).

            4 · Grammar: French tenses

            The Study card opens an 18-chapter French tenses course based on the DELF B2 handbook. Each chapter has a bilingual explanation (switch VI / EN at the top), conjugation tables, examples with audio, common traps, and short exercises. Correct answers are saved in this browser; a chapter is marked complete when you finish all its exercises or press Mark lesson complete. Progress appears on the Study card and the course map.

            The AI tutor on each lesson uses the same Settings → AI setup as the rest of VocabLab: in Simple mode it works without a key; in Advanced it uses your provider. Ask for a simpler explanation, extra examples, a correction, or a short quiz. The tutor keeps the lesson context, so questions such as “why is this imparfait?” get an answer about the chapter you are reading.

            Troubleshooting

            • 403 from Sheets — the sheet isn't shared as “Anyone with the link”, or the API key has restrictions that block the Sheets API.
            • “API has not been used / disabled” — enable the Google Sheets API for your key's project.
            • AI errors — in Simple, press “Check the free AI” (Settings → AI); if the free service is busy, retry in a minute or move to Advanced. In Advanced, check the key (“Test & load models”), or switch Generator to Built-in. The app keeps the whole explanation in Settings → AI.
            • Ollama / local server — Ollama is a program on your computer, not a web service: install it (ollama.com/download), run ollama serve, then ollama pull llama3.2. “nothing is running there” means VocabLab couldn't find it on that port; “a server answered, but it blocked this page” means CORS (OLLAMA_ORIGINS=*, and serve this page over http(s)://).
            • 429 quota — free-tier limit hit. Wait a minute, or pick another provider in Advanced: Groq, Cerebras and OpenRouter have free tiers of their own. Built-in questions cover the rest meanwhile. In Simple, the free shared service can be busy — retry, or switch to Advanced.
            • Network errors — if you opened the file directly (file://), try serving the folder (python3 -m http.server) or hosting it. Some browsers restrict cross-site requests from local files.
            • Speaker icons are silent — use the Test speaker button on the home screen; it reports how many browser voices are available. On Linux, Chrome does not use speech-dispatcher; use Firefox and restart it after starting speech-dispatcher. If you configured Azure, the same button tests the neural voice and opens Settings → Speech with the exact error if the key, region or network is wrong.
            • Azure says the key or region is wrong — the key and region must belong to the same Azure Speech resource. Copy the region from the resource's Keys and Endpoint page (for example southeastasia), not the resource group location. A new free F0 resource can take a minute to become active.
            • Pronunciation scoring is disabled — recording still works without a scoring key, but scores need a free Gemini key in Settings → AI or an Azure key in Settings → Speech. If the button says you have no microphone, allow microphone permission for this site; browsers also require https:// or localhost for recording.
            • Gemini scoring fails — check the Gemini key in Settings → AI (“Test key & load models”). Free-tier audio limits reset within a minute; a 403 can also mean audio input is not available for that key's region, in which case switch Pronunciation scoring to Azure.
            • Shadowing is greyed out — Start shadowing needs AI to write the paragraph (Simple mode is enough). A scoring key is only needed after you record: Gemini in Settings → AI, or Azure in Settings → Speech.
